## 📌 About

This repository contains my solutions to programming problems using **C++**, as I build my problem-solving skills and prepare for competitive programming and ICPC.

I'm documenting my progress from the fundamentals, focusing on understanding the logic behind each problem rather than simply getting an accepted answer.

## 🎯 What I'm Practicing

- **Programming Fundamentals** — variables, data types, operators, and input/output.
- **Conditions & Logic** — conditional statements and decision-making.
- **Loops** — iteration, counting, and repetitive operations.
- **Mathematical Problems** — divisibility, prime numbers, powers, and arithmetic.
- **Problem-Solving** — breaking problems into smaller, logical steps.
- **Competitive Programming** — practicing constraints, edge cases, and correctness.

## 🛠️ Tech Stack

- **Language:** C++
- **Compiler:** GCC / G++
- **Practice:** Programming exercises and ICPC preparation

## 📂 Repository Structure

Solutions are organized around the topics and exercises I'm practicing, making it easier to track progress and revisit previously solved problems.

## 🧩 My Approach

1. Understand the problem and its constraints.
2. Identify the required logic.
3. Implement a solution in C++.
4. Test different inputs and edge cases.
5. Review incorrect submissions and improve.
